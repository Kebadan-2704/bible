# 14 — Prioritized Engineering & UX Action Plan

**Audit Target:** Trinity International University (`trinity-international-university`)  
**Prioritization Scale:**  
- **P0 (Blocker — Fix Before Any Public Launch):** Breaks core navigation, mobile usability, data reliability, legal/brand trust, or security.  
- **P1 (High Priority — Fix in Pre-Launch Sprint):** Broken promised features, WCAG 2.2 AA violations, CWV CLS failure, SEO metadata gaps, broken CSS tokens.  
- **P2 (Medium Priority — Post-Launch Polish):** Architecture cleanup, visual/imagery upgrades, bundle size reduction, UX enhancements.  
- **P3 (Low Priority — Strategic Roadmap):** Competitive differentiation, rich schema, automated E2E suite.
